# Welcome to YueMi

YueMi turns a folder of Markdown and CSS into a print-ready PDF.

This document is a **sample project**. Open the `examples/welcome` folder
from the app to try it.

## What this shows

- Headings become the outline in the sidebar, with page numbers taken from
  the rendered PDF.
- The stylesheet controls typography, margins, and the running footer.
- Everything is plain text, so the project works with git.

## Working with the preview

The preview on the right updates as you type. It is not an approximation of
the PDF: it *is* the PDF, rendered in the app. What you see in the preview is
exactly what the exported file contains.

> Edit any text and watch the page count change.

## Exporting

Use **Export PDF** in the toolbar to save the document. The bytes written to
disk are the same bytes the preview showed, so the two can never drift apart.
